Upload all website files together to the root of your GitHub Pages repository.

After publishing, refresh the page. Existing question IDs and saved progress are retained.

SQL
Run OneExam-Learn-30-Lessons.sql in your Supabase SQL Editor to publish the learning library.
The website also includes the 30 lessons as a fallback if that library cannot be reached.
Rerunning the seed restores its 30 supplied lesson records, including published status; back up any custom edits first.
The questions are bundled in expanded-questions.mjs: uploading the website adds them. They do not need SQL.
For a brand-new installation only, run OneExam-Account-Setup.sql as described in your original account setup.
No SQL was executed against your live project during preparation.
